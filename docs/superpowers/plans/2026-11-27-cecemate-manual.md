# CeCeMate 产品手册知识扩展开发计划

目标：在现有聊天中默认提供手册问答，使用本地只读知识扩展和现有 knowledge_search，保留来源证据。

已确认设计：所有已登录用户共享；不展示选择器；语料随扩展版本发布；原始手册不入 Git；不核验或修正手册业务事实；冲突保留原文；下线仅继承手册明确标注章节。

技术：Python 扩展、结构化 JSON、中文检索与 BM25、现有知识引用契约。无新增服务。语料初始化读取，检索请求不执行磁盘 I/O。

## 任务

- [x] 生成可重复构建的语料及来源审校记录，测试表格、下线继承和内容保留。
- [x] 实现提供方、配置校验、本地检索、证据预算和包资源，测试自然语言、无匹配、下线与跨模块问题。
- [x] 通过扩展管理器安装受控快照，配置本地及两环境示例，补充产品问答优先规则。
- [x] 校验安装、引用和配置，执行包测试、相关回归及静态检查。
- [x] 文档记录更新、重启、回滚、验收结果与未验证项；不提交或推送。

## 重点验证

未知问题不得强行返回相近结果；已下线的独立公告不能遮蔽招中标公告；原文中的冲突不被重写；片段预算不能截断口径造成误导；无知识选择器时检索默认可用。

## 实施记录

语料 164 条，159 有效、5 下线，来源行归属无缺口。使用无额外依赖的中文双字词元与 BM25，匹配别名和场景词；每条证据最多 800 字符、总计最多 4800 字符和 6 条，适配现有引用预算。自然问句通用词过滤及主题覆盖门槛用于减少无关召回，不作为可信概率。

原文没有明确字段标签时保留完整正文，结构化字段留空；不同章节相同功能保留各自来源，不做语义强制合并。七个完整需求问句、评分维度、下线、无关能力负例及通用工具证据回放已纳入测试。

集成测试发现原有 Qwen Flash 配置的 unsupported 与开启分支不兼容，调整为基础 extra_body.enable_thinking=false、关闭分支仍显式 false、开启分支为空；应用配置校验和模型相关测试通过。

已完成本地扩展安装，未重启正在运行的 Gateway、未调用实际业务模型、未部署服务器。后续须重启 Gateway 并以实际模型进行聊天验收。管理器同步时移除的原有六项可选依赖已恢复。
