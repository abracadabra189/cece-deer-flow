## 一、核心扩展能力

> DeerFlow 的本质是 **Agent Harness（智能体运行时底座）**：业务方能在这里接入数据、沉淀能力、定制角色，而不必改动核心代码。

### 1. MCP 服务接入（最高优先级扩展通道）

**功能说明**：原生支持 stdio / SSE / HTTP 三种 MCP 传输协议；在 `extensions_config.json` 中声明即接入，支持热重载、OAuth 2.0 自动刷新、stdio 会话池复用、按用户隔离的个人级 MCP。

**能做什么（示例）**：
- 接入内部 **PEVC 融资数据库** → Agent 直接回答「这家公司上一轮融资多少、谁投的」
- 接入**企业工商数据 MCP** → 一句话完成企业背景穿透核查
- 接入**人物洞察 MCP** → 查询高管履历、关联关系网络
- 接入**实体识别 MCP（NER）** → 从长文本中自动抽取公司/人物/产品实体
- 接入内部 CRM / 工单系统 → 客服 Agent 直接创建、查询工单
- 接入 Dify 知识库 / 数据库 → 把存量业务系统变成 Agent 可调用的工具

**支持的产品形态**：企业数据问答台、投研数据终端、智能客服后台。

---

### 2. 技能系统（Skill = Markdown，能力即文档）

**功能说明**：技能是一个 `SKILL.md` 文件（YAML 元数据 + Markdown 指令），声明名称、描述、可用工具、所需密钥即可成为 Agent 能力。内置 23 个技能，支持渐进式加载、双层覆盖、显式激活。

**能做什么（示例）**：
- 用 `/deep-research` 技能 → 输出一份带引用的深度行业研报
- 用 `/ppt-generation` → 把研报结论直接转成投委会 PPT
- 用 `/data-analysis` → 上传 Excel 自动跑 pandas 分析并出图
- 用 `/consulting-analysis` → 按咨询框架（波特五力/SWOT）拆解业务问题
- 自建「**尽调清单技能**」→ 沉淀公司专属的尽调 SOP，全团队复用

**支持的产品形态**：研报助手、咨询顾问、数据分析师、内容工作室。

---

### 3. 自定义 Agent（SOUL.md 人格注入）

**功能说明**：用户可创建独立角色的 Agent——自定义人设提示词（SOUL.md）、专属模型、工具组白名单、子代理白名单、专属技能集，彼此完全隔离。

**能做什么（示例）**：
- 创建「**投研分析师**」：只配金融 MCP + 研报技能，回答专业且不乱用工具
- 创建「**法务合同审查员**」：只读文件 + 合同知识库，不联网不执行代码
- 创建「**高管数字分身**」：写入其履历、口吻、决策风格，在 IM 群里代为应答
- 创建「**客服专员**」：绑定工单 MCP + 产品知识库，7×24 在线

**支持的产品形态**：数字分身、垂直岗位 AI 同事、专属客服。

---

### 4. 工具扩展（函数即工具）

**功能说明**：在 `tools/` 目录写一个 Python 函数 + config.yaml 声明一行 `use: 模块:函数`，即完成注册；社区已内置 29 个工具目录（搜索、抓取、浏览器、图片、知识库等）。配合 `tool_search` 延迟加载，接入数百工具也不撑爆上下文。

**能做什么（示例）**：
- 写一个「**内部估值计算函数**」→ Agent 获得标准化估值能力
- 接入「**企业微信审批流 API**」→ Agent 直接发起报销/请假审批
- 写「**舆情打分函数**」→ 对每日抓取的新闻自动打情感分入库
- 复用社区 `browser_automation` → Agent 操作无 API 的老旧系统页面

**支持的产品形态**：流程自动化、舆情监控台、RPA 替代方案。

---

### 5. Python 扩展（Extensions，平台级插件）

**功能说明**：可信 Python 包经 `config.yaml plugins:` 加载，可贡献中间件、生命周期观察者、FastAPI 路由、Gateway 服务、全栈插件；支持安装/升级/启停/移除的完整 CLI 生命周期。

**能做什么（示例）**：
- 写「**企业审计插件**」→ 所有 Agent 工具调用同步上报内部审计系统
- 写「**计费插件**」→ 按部门统计 Token 用量并对接财务系统
- 写「**内容审核中间件**」→ 对外服务时过滤敏感回答
- 参考 `examples/deerflow-extension-bookmarks` 快速起步

**支持的产品形态**：企业合规平台、多租户计费 SaaS。

---

### 6. 子代理编排（并行 + 批处理）

**功能说明**：Lead Agent 通过 `task` 工具把子任务委派给隔离上下文的子代理并行执行；`batch_task` 支持持久化批量任务（租约恢复、暂停/恢复/取消、失败重试、JSONL 导出）。

**能做什么（示例）**：
- 「**同时分析 50 家可比公司**」→ 批处理队列隔夜跑完，中断续跑
- 写研报时**并行**执行：查公司 A、查公司 B、跑财务模型，三路同时推进
- 批量**代码迁移**：100 个文件逐个交给子代理改写，主线程只看汇总

**支持的产品形态**：批量尽调流水线、全量数据扫描、大规模内容生成。

---

### 7. 技能自生产（skill-creator + skill-reviewer）

**功能说明**：对话式描述需求，Agent 自动起草 SKILL.md、写辅助脚本、跑测试并迭代修复；审查工具对技能包做静态安全扫描与质量评估，可执行内容阻断、CI 豁免清单管控。

**能做什么（示例）**：
- 业务人员对 Agent 说「**帮我做一个周报技能**」→ 自动生成、自动测试、即刻可用
- 管理员审核第三方技能包 → 杜绝带后门的技能混入平台
- 团队按月沉淀新技能 → 平台能力随业务成长复利积累

**支持的产品形态**：企业内部能力市场、团队知识资产库。

---

### 8. 多渠道接入（IM 渠道矩阵）

**功能说明**：飞书、Slack、Telegram、Discord、企业微信、钉钉开箱接入；渠道消息自动映射到线程，回复自动回投；渠道级用户白名单与文件类型管控。

**能做什么（示例）**：
- 在**飞书群**里 @机器人：「查一下 XX 公司融资历史」→ 直接群内回复
- **钉钉定时推送**：每周一早 8 点行业周报到群
- **企微客服**：客户在企微提问，Agent 调知识库 + 工单系统闭环处理

**支持的产品形态**：IM 原生 AI 同事、群机器人客服、自动播报员。

---

### 9. Python Client 嵌入式调用

**功能说明**：`deerflow-harness` 包可在任意 Python 进程内直接调用（`client.chat()` / `client.stream()`），与 Gateway 共享配置和数据目录，不经 HTTP。

**能做什么（示例）**：
- 在自己的 **ETL 脚本**里嵌入 Agent：数据清洗完自动生成摘要报告
- 在 **Jupyter Notebook** 里边跑数边让 Agent 解释结果
- 在现有 **Web 系统**后端嵌入 Agent 能力，不重造前端

**支持的产品形态**：能力中台、内部工具增强、自动化脚本智能化。

---

### 10. 记忆系统扩展（多后端）

**功能说明**：三层记忆架构（共享摘要 + Markdown 事实 + FTS5 检索索引）；默认 DeerMem 后端之外，支持 mem0 / OpenViking / Honcho 远程后端；写入门 fail-closed 防污染。

**能做什么（示例）**：
- **投研场景**：Agent 记住「上次对 XX 赛道的结论是谨慎」，下次调研自动带上历史判断
- **客服场景**：记住每个客户的历史问题与偏好，无需重复询问
- **数字分身**：持续吸收本人交互记录，回答越来越像本人

**支持的产品形态**：个性化助手、客户成功系统、长期陪伴型 AI。

## 二、平台核心功能

> 开箱即用的产品级能力，让 Agent 的「不确定性」被包进确定性的用户体验里。

### 1. 四种执行模式（flash / thinking / pro / ultra）

**功能说明**：一档一句话的复杂度分级：flash 直答、thinking 思考链、pro 计划模式、ultra 全开（计划 + 子代理并行 + 高推理强度）。

**示例**：问「今天日期」用 flash（秒回省钱）；「做一份行业研报」用 ultra（规划 + 并行调研 + 深度推理）。

### 2. 计划模式（TodoList 任务清单）

**功能说明**：Agent 自主维护任务清单逐项推进，UI 实时展示进度；防摘要丢失、防提前收尾。

**示例**：「调研→分析→成稿→排版」四步任务，用户随时看到做到哪一步。

### 3. 上下文工程（自动摘要 + 手动压缩）

**功能说明**：接近上下文上限自动摘要（保留最新请求与关键台账）；`/compact` 手动压缩；超大工具输出自动落盘替换为引用。

**示例**：百轮调研对话不失忆；100MB 日志分析结果不撑爆上下文。

### 4. 文件上传与引用

**功能说明**：PDF/PPT/Excel/Word 上传自动转 Markdown 注入上下文；分片暂存 + 原子落位。

**示例**：上传一份 200 页招股书，直接问「这家公司毛利率趋势如何」。

### 5. 优化输入（Input Polish）

**功能说明**：发送前对草稿做一次性 LLM 润色，补全意图与约束。

**示例**：用户随手打「分析下这个」，润色后变成带范围、格式、深度要求的明确指令。

### 6. 对话建议（智能追问）

**功能说明**：每轮回答后自动生成追问建议，点击即继续。

**示例**：研报出来后自动建议「要不要对比同行业公司？」「要不要生成 PPT？」。

### 7. 定时任务（Scheduler）

**功能说明**：类 cron 调度，非交互执行、排队防重入、IM 通知投递。

**示例**：「每周一 8:00 生成行业周报并发到飞书群」——一次配置，永久自动。

### 8. 制品管理（Artifacts）

**功能说明**：产出物按线程隔离存储，字节范围流式读取、原子覆盖（SHA-256 校验）、前端在线预览与编辑。

**示例**：Agent 写的报告.md、图表.png、分析.ipynb 直接在线查看、编辑、下载。

### 9. 项目管理

**功能说明**：线程归入项目，项目级文档架共享资料。

**示例**：「XX 赛道研究」项目下挂几十次调研、几十份资料、最终报告集中管理。

### 10. 对话分支与编辑重跑

**功能说明**：从任意一轮分叉新对话；修改历史提问重跑后续。

**示例**：「换个问法试试」不用重开窗口，试错成本归零。

### 11. /goal 目标管理

**功能说明**：为线程设定完成条件，Agent 每轮自检，达成前持续推进。

**示例**：设定「产出可交付报告」后，Agent 不会半途给个半成品就停。

### 12. SSE 流式与断线续传

**功能说明**：执行过程实时推送；`Last-Event-ID` 断点重连；回放缺口自动恢复。

**示例**：30 分钟的研报任务跑到一半刷新页面，进度无缝接上。

### 13. 多模型治理

**功能说明**：多 Provider 并存、能力标记、四级容错（名称回退/授权回退/重试熔断/推理协商）、RPM 限流、成本估算。

**示例**：贵模型攻坚研报、便宜模型跑摘要；某模型宕机自动降级不中断服务。

### 14. 浏览器自动化 + Live 视图

**功能说明**：Playwright 驱动浏览器操作，前端 WebSocket 实时观看。

**示例**：Agent 登录内部系统截图取证，用户实时看着它点——透明可信。

### 15. 澄清交互（Ask Clarification）

**功能说明**：歧义处主动发起结构化提问卡片（单选/表单/自由文本）。

**示例**：「帮我订机票」→ Agent 反问「出发地是北京还是上海？」而非瞎猜。

### 16. 语音输入与视觉理解

**功能说明**：浏览器语音转文字；vision 模型自动获得图片查看工具。

**示例**：截一张财报图片发过去，直接问「这个指标为什么下滑」。

### 17. 反馈与控制台

**功能说明**：运行级点赞/点踩统计；跨线程用量与成本可视。

**示例**：运营周报直接看「哪类任务差评多、哪个模型最烧钱」。

## 三、安全与治理能力

> Agent 能执行代码，所以每一层都假设它会出错或被攻击。

### 1. 每任务独立容器

**说明**：任务在独立 Docker/K8s 容器中执行，结束即销毁（或进暖池），零共享文件系统。

**示例**：Agent 执行 `rm -rf /` 也只影响一次性容器，宿主机与其他任务免疫。

### 2. 虚拟路径映射

**说明**：Agent 只见 `/mnt/user-data/*` 虚拟路径，宿主真实路径不可见，用户/线程级目录隔离。

**示例**：A 用户的财务文件永远不会落到 B 用户的磁盘目录。

### 3. 沙箱授权门 + 审计

**说明**：每次沙箱获取前强制 `sandbox:execute` 授权检查；所有 shell/文件操作分类审计留痕。

**示例**：未经策略批准的 Agent 实例连 bash 都拿不到；出事后可精确追溯「谁在何时执行了什么」。

### 4. 输入/工具结果双重消毒

**说明**：用户输入包裹边界标记防注入；远程工具返回中伪造的框架标签被中和。

**示例**：恶意网页里藏的「忽略之前的指令」无法劫持 Agent。

### 5. PII 脱敏

**说明**：输入与记忆写入前正则脱敏。

**示例**：身份证号、手机号不进日志、不进长期记忆。

### 6. 写前读校验

**说明**：基于哈希校验——改文件前必须先读过当前版本。

**示例**：防止 Agent 用过期认知覆盖掉同事刚改的配置文件。

### 7. 技能安全扫描

**说明**：技能包安装前静态扫描；审查工具只读分析；CI 豁免清单管控。

**示例**：第三方技能里夹带的数据外泄脚本在安装前就被拦下。

### 8. 认证与限流

**说明**：本地 + OIDC/SSO；弱密码黑名单；登录按 IP 限流；HttpOnly Cookie；CSRF 双提交。

**示例**：爆破、XSS 窃令牌、CSRF 等常见攻击面全覆盖。

### 9. SSRF 防护

**说明**：内网地址默认拒绝，需显式放行。

**示例**：Agent 无法被诱导访问云元数据接口或内部管理系统。

### 10. 密钥零硬编码

**说明**：全部 `$ENV_VAR` 引用，启动时解析，写回配置绝不落明文。

**示例**：config.yaml 可安全提交 Git 仓库。

### 11. 记忆写入门（Fail-Closed）

**说明**：LLM 抽取的记忆提案必须携带 scope/durability/authority 三标签，缺一即拒。

**示例**：幻觉、随口一说、注入的伪造事实都污染不了长期记忆库。

### 12. 循环检测与 Token 预算

**说明**：死循环自动熔断；单次运行 Token 有上限；子代理三重上限。

**示例**：Agent 失控时烧钱有底——预算到顶自动停。

## 四、概念产品与应用示例

> 以下产品形态均为 **DeerFlow 能力的组合配置结果**，不是独立软件。

### 1. 数字分身（Digital Twin）

**能力组合**：自定义 Agent（SOUL.md 人格）+ 三层记忆 + person-insight-mcp + IM 渠道

**落地示例**：高管分身在飞书群替本人回答常规问题；资深分析师分身把投研逻辑沉淀为可对话资产；关键员工离职后知识留在平台。

### 2. 智能研报助手

**能力组合**：deep-research 技能 + finance-mcp + enterprise-mcp + 子代理并行 + chart-visualization + ppt-generation + 定时任务

**落地示例**：输入赛道名 → 自动扫描可比公司 → 出数据图表 → 生成投决 PPT → 每周一自动更新。

### 3. 企业尽调助手

**能力组合**：enterprise-mcp + entity-resolve-mcp + 文件上传解析 + 计划模式 + 制品管理

**落地示例**：输入公司名称，自动完成工商核验 → 关联图谱 → 风险扫描 → 尽调报告成稿。

### 4. 行业情报监控台

**能力组合**：定时任务 + web 搜索工具集 + 记忆增量 + IM 通知

**落地示例**：竞品动态、政策变化、技术趋势每日监控，早报直推工作群。

### 5. 内容创作工厂

**能力组合**：newsletter/podcast/video/music/image 生成技能矩阵 + 计划模式编排

**落地示例**：一个选题进来，图文、音频、视频、配图多形态内容一次产出。

### 6. 数据分析助手

**能力组合**：data-analysis 技能 + 文件上传 + 沙箱真实跑数 + 自我纠错闭环

**落地示例**：业务人员上传表格说「分析下这个月销售」，直接拿到结论与图表。

### 7. IM 原生智能客服

**能力组合**：IM 渠道 + 自定义 Agent + 内部系统 MCP + 澄清交互

**落地示例**：住在企业 IM 里的全能同事——查数据、提工单、答制度、办流程，一句话的事。
