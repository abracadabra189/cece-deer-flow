# 周报数据口径

本文件定义周报内部数据对象。所有表格、KPI、排行和正文必须引用同一份已标准化的事件集合，不得在写 HTML 时重新计算。

## 融资事件标准字段

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `company_name` | 融资方工商全称 | 可由 NER 消歧；无法确认时保留信源名称并标待核 |
| `event_date` | 融资日期 | 用于周期筛选与去重 |
| `finance_round` | 融资轮次 | 保留信源值；默认只接受天使、Pre-A、A、A+ |
| `amount_wan` | 披露融资金额，单位万元 | 仅数值型、已披露金额可填；未知为 `null` |
| `investors` | 本轮投资方 | 去除“不公开的投资者”等占位值后再统计 |
| `industry_node` | 信源原始产业节点 | 不因公司简介改写 |
| `industry_chain` | 周报分组产业链 | 每条事件只能归入一个产业链 |
| `city` | 地级市；直辖市到区 | 缺失写“未公开” |
| `evidence_level` | `db` / `media` / `pr` / `inferred` | 只可下调不可上调 |
| `source_note` | 数据限制或待核说明 | 不展示为工具或字段信息 |
| `event_id` | 数据源事件唯一标识 | 有值时作为首选去重键 |

## 去重、金额与轮次

- 首选数据源 `event_id` 去重。无唯一标识时，使用“融资方 + 融资日期 + 融资轮次 + 已披露金额 + 本轮投资方摘要”作为回退键；仅用“融资方 + 融资日期”会误合并同日不同融资，不可作为唯一规则。
- 金额 `null`、空值和 `0.00` 都表示“未披露”，不参与合计、金额排序或大小天使划分。
- 展示金额：不低于 1 亿元写为 `X.XX 亿元`；低于 1 亿元写为 `XXXX 万元`；不得展示裸数字或“0 元”。
- 不以注册资本替代融资额，不取均值、中值或推算值填充融资额。
- 默认以 10,000 万元为大/小天使分界；金额未披露的天使轮单列，不划分大小天使。单笔披露金额低于 5 万元时标为“待核”，不进入金额主排序。
- 种子轮、B 轮及以后、战略融资与并购默认不进入主表；如用户要求变化，必须在报告口径中说明。

## 产业归类

- 产业节点照录数据源原始标签；产业链仅用于分组，不覆盖产业节点。
- 一条事件只归入一个产业链，所有产业链事件数之和必须等于去重后总事件数。
- 默认产业链及归集关键词如下：半导体（芯片、半导体、集成电路、光芯片、光电子器件、电子专用材料、MEMS 传感器）；人工智能（人工智能、大模型、AIGC、算力、agent、智能体、智能交互、机器学习、算法、多模态、NLP、人工智能基础软件）；生物医药（生物技术、制药、医药、基因、细胞、疫苗、蛋白、抗体、免疫、原料药、保健食品）；医疗器械（医疗仪器、医疗器械、诊断设备、治疗及护理设备、医疗级脑机接口）；数字经济（数据服务、物联网平台、工业互联网、网络安全、数字运营）；商业航天（卫星、遥感、火箭、商业航天研制平台、低空飞行器）；前沿科技（量子计算、量子芯片、量子编程、VR/AR、元宇宙、可控核聚变）；企业软件（软件、SaaS、系统集成、行业解决方案、信息服务）；新能源（光伏、风电、储能、氢能、充电桩、动力电池及材料）；新材料（高温合金、特种树脂、电子材料、正极材料、超导、复合材料）；机器人（机器人本体、具身智能、智能机器人、无人车、自动驾驶）；智能装备（无人机、工业自动化装备、机床、精密机械）；智能硬件（消费级智能硬件、摄像头/传感器模组、智能终端）；先进制造（精密零部件、轴承、仪器仪表、增材制造）；其他（未命中）。
- ASCII 关键词 `ai`、`vr`、`ar`、`saas` 按词边界匹配，避免将 `retail`、`training` 等误命中。产业链只用于分组，绝不把相近产业合并命名。
- “其他”占比高于 30% 时，在数据说明中指出标签覆盖局限，不要静默重写标签。

## 重点项目选择

从清洗后的事件中选择 5–10 家做项目深度分析。优先考虑金额异常、头部机构或产业方参与、首次出现的细分方向、成立较短但注册资本较高，或用户特别点名的项目。

选择是研究优先级，不构成投资建议。证据不足时宁可少选，不以推断补足。

## 证据分级与字段体检

- `db`：结构化数据直出，可写为确定事实；`media`：单一媒体来源，需标明来源；`pr`：仅单一通稿，投资机构后标“据单一通稿”；`inferred`：只可出现在“待核”表述中。
- 级别只能下调，字段缺失时不得为了完整性上调为 `db`。
- 进页面前检查融资方、融资轮次、融资金额（万元）、融资日期、投资方、新华产业六项核心字段。任一字段整列为空时，先判定为可能的字段漂移，停止相关结论并复核当前 MCP 契约。
- 原始每页响应原样写入 `raw/week_YYYYWW_p<N>.json`；重点项目详情写入 `raw/highlights_YYYYWW.json`。原始文件不手工改写。
