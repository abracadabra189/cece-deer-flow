# 早期科技项目融资周报规范

## 报告定位

面向投资团队的国内早期科技项目周度监测。报告陈述可核验事实与基于事实的观察，不提供买入、回避、评级等投资建议。

HTML 为单文件、可打印交付物。按 `cecemate-format/references/web-spec.md` 直接生成完整页面，优先内联品牌 Logo，使用同一份已核验的汇总结果填写全部数字与表格。生成后运行 `cecemate-format/scripts/check_web_required.py`，校验页头、页脚 Logo 和 `main` 末尾的免责声明；本文件定义业务内容，网页规范定义版式要求。

## 页面结构

1. **报头与信息条**：固定主标题“早期科技项目融资周报”，展示期次、监测区间、监测范围、事件数及已披露金额的口径。
2. **内容提要**：严格包含六块：一句导语（事件数、披露金额、轮次构成、重点/信号条数）、四张关键数字卡、轮次构成、披露金额前三项目（最多三行）、融资金额前十产业节点、数据说明。提要只呈现统计事实，不写判断。
3. **融资速览**：按产业链分组的主表，字段为序号、项目、轮次、金额、产业节点、实控人、投资机构、地区。每组独立表头，序号跨组连续，组内按已披露金额降序，未披露金额排后。
4. **重点关注项目**：默认 5 家、范围 5–10 家。每家固定包含融资信息、双产业标签、实控人与核心团队、六行关系网络、事实与观察分段、2–4 家同业对比。取不到的字段写“未公开”或“待核”。
5. **本周赛道信号**：只讨论由本期数据支持的两类信号：同一产业节点当周不少于 3 起融资的产业集中度；金额异常（天使轮不低于 5 倍分界线、A 轮不低于 20 亿元、单轮出让超过三成、一个月内连续两轮融资）。
6. **核心洞察**：3–5 条，每条采用“现象 → 解读 → 线索”；事实来源或待核状态在页尾说明。
7. **页尾说明**：按“已核查说明 → 口径说明 → 数据截至日”的顺序呈现，并保留 `cecemate-format` 要求的免责声明。

## 重点项目规则

每个重点项目优先包含：

1. 融资轮次、金额、日期、本轮投资方与已核验的出让比例；
2. 所属产业链与原始产业节点，两枚标签只写名称；
3. 实控人、核心团队、股东与高管信息；
4. 固定六行关系网络：股东线、实控人穿透、员工持股平台、投资方线、任职线、关联企业；
5. 事实段与观察段分离；
6. 2–4 家同业对比对象及可核验的比较维度。

图谱或人物数据不可用时，删除无法证实的推断，不得以完整六段式为由补造信息。

## 文案红线

- 不出现 MCP、接口、字段、工具、分页或内部流程。
- 不把融资金额、注册资本、估值或持股比例相互替代。
- 不用“建议关注”“建议回避”等投资建议语言。
- 不把单一通稿、媒体信息或推断写成确定事实。
- 不因版式需要编造项目、机构、产业标签或排名。
- 不出现“建议关注”“建议回避”等投资建议；“金额前三”只是事实排序，观点仅在核心洞察中基于证据表达。
