# CeCe MCP 取数指南

本文件记录早期项目投资周报需要的 CeCe MCP 能力。工具名、参数与字段可能迭代，调用前以当前会话中模型可见的工具说明为准；下列映射用于确定取数目标、调用顺序与失败处理。

## 服务分工

| 服务 | 主要职责 | 在本报告中的级别 |
| --- | --- | --- |
| NER | 企业名称、产业与区域规范化 | 按需 |
| PEVC | 融资事件主检索、机构投资与 LP 信息 | 融资主检索必需，其余按需 |
| enterprise | 企业基础信息、图谱、股东、高管、历史融资 | 重点项目必需 |
| person | 由企业图谱主体标识继续查询控制、持股与关联 | 有可用实控人标识时必需 |

## 工具映射

### NER

| 当前映射 | 用途 | 约束 |
| --- | --- | --- |
| `search_enterprise_by_name` | 品牌或简称规范为工商全称 | 同名时保留待核，不猜测 |
| `get_industry_tree` | 将用户产业词规范为检索条件 | 仅在用户指定产业时调用 |
| `get_region_tree` | 将用户区域词规范为检索条件 | 仅在用户指定区域时调用 |
| `search_person_by_name` | 人名检索 | 不用于实控人消歧，仅作非关键补充 |

### PEVC

| 当前映射 | 用途 | 级别 |
| --- | --- | --- |
| `search_financing_companies` | 周期内融资事件主检索 | 必需 |
| `get_fund_detail_investment_list` | 机构近期开出，辅助赛道信号反查 | 可选 |
| `get_fund_detail_investor_list` | 机构 LP 结构，辅助说明机构属性 | 可选 |

融资主检索通常需要日期区间、轮次、区域、产业、页码与页大小等条件。默认轮次为天使、Pre-A、A、A+；不要传金额范围，否则可能排除金额未披露事件。

- 从第一页开始持续翻页，直到当前实时工具返回空列表才停止；不要将某页摘要中的数量视为总数。
- 每页原样落盘后再进入同一标准事件集合，按 `data-contract.md` 的事件 ID 优先、复合键回退规则去重。
- 先取全量事件，再统一筛选和汇总；不要在生成 HTML 时边查边算。

### enterprise

| 当前映射 | 用途 | 级别 |
| --- | --- | --- |
| `get_enterprise_basic` | 注册资本、成立日期、地址、经营范围、经营状态 | 重点项目必需 |
| `get_company_graphy` | 对外投资、融资来源方、实际控制人、股东、高管、受益所有人 | 重点项目必需 |
| `get_enterprise_shareholders` | 前三大股东及比例 | 重点项目优先 |
| `get_enterprise_management` | 董监高名单 | 重点项目优先 |
| `get_enterprise_VCPE_financing` | 历史轮次与历史投资方 | 重点项目优先 |
| `get_enterprise_tags` | 产业、科技资质或风险标签 | 可选 |

`get_company_graphy` 返回的“实际控制人”主体标识是人物服务的唯一可信起点。图谱中的融资来源方可与本轮投资方、历史融资记录交叉比对，以识别老股东加注；无法证实就不下结论。

### person

| 当前映射 | 用途 | 级别 |
| --- | --- | --- |
| `get_person_holder` | 直接经济权益与持股路径 | 有人物主体标识时优先 |
| `get_person_partner` | 控制比例、合伙人及角色 | 有人物主体标识时优先 |
| `get_person_controller` | 实控企业清单 | 可选 |
| `get_person_union` / `office` / `legal` / `beneficial` | 关联企业、任职、法人、受益所有人 | 可选 |

不得从同名人搜索结果猜测 `person_no`。直接持股与控制比例是不同口径，必须分开写；图谱无法穿透至自然人时，明确写“未能穿透至自然人”，不能以法定代表人替代。

## 调用顺序与节流

1. 若用户给出区域、产业或简称，先通过 NER 规范条件。
2. 用 PEVC 完成融资主检索、翻页、去重和标准化。
3. 基于统一事件集合选择重点项目。
4. 针对每个重点项目依次查询 enterprise 基础信息、图谱、股东、高管和历史融资。
5. 仅对图谱给出的实控人主体标识调用 person 服务。

取数完成后、渲染前必须完成以下体检：六项核心字段不整列为空；分页以空列表结束；非早期轮次的剔除数已记录；“不公开的投资者”等占位投资方剔除后，剔除处数已记录；金额未披露数已记录。任何字段漂移都优先按当前工具说明核对，不能靠历史字段名猜测。

默认串行处理同一企业的详情链路，连续详情调用间隔不少于 1 秒；若运行时工具说明给出更严格的配额，以其为准。不要为“看起来全面”而批量枚举无关企业、机构或人物。

## 失败处理

| 情况 | 处理 |
| --- | --- |
| 融资主检索失败 | 中止本期报告，说明数据源不可用；不换用其他数据源 |
| 融资主检索分页中途失败 | 默认中止，不以已取得的页面生成完整周报；用户明确接受时才标注为不完整交付 |
| 单家企业详情失败 | 重试至多 2 次；仍失败则只保留融资信息，改选次优项目 |
| 图谱失败 | 标记“图谱取数失败，实控人待核”；不以法人替代 |
| 人物持股无返回 | 写“股权结构未公开”，不补造比例 |
| 核心字段整列为空 | 先检查实时工具字段与映射是否漂移；未确认前不生成该项结论 |
