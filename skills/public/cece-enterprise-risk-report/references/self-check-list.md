# 企业风险监控报告 · 自检清单

> 报告生成后通读全文逐条核对。代码体检查格式与残留，本清单查内容质量与逻辑。两层都过才能交付。

## 一、结构与覆盖度

- [ ] 概述/行业分析/重点企业深化/信号提示/总体研判 结构齐全
- [ ] 行业节按集合实际行业分布组织，编号连续
- [ ] 每个行业节：【行业动态】+【区内动态】+ 重点企业动态表
- [ ] 行业表格覆盖该行业集合内实际有动态企业的 top5（不是手写概括 1-2 家）
- [ ] 重点企业每家四段式（重要动态/股东结构/业务布局/风险分析）
- [ ] 附录1（监测名录）齐全；含新注册企业时附录2齐全（大量级时为精选名录+完整数据文件指引）
- [ ] 新注册部分按数量级分级：少量全量名录 / 中量分类统计 / 大量总体画像+特写top N

## 二、内容质量（通读判断）

- [ ] 行业动态段含：行业趋势 + 当期数据/政策 + 具名事件（无模板化填充）
- [ ] 区内动态段落到集合内企业本期实际动态（无套话雷同）
- [ ] 各行业结论互不相同
- [ ] 重点企业风险分析四步推导齐全且互不相同
- [ ] 动态列每条=时间+事件+当事人+金额/案号（无字段标签、无空字段标签如"原告：，"）
- [ ] 研判列=分类计数+含义（专利不计入开庭/涉诉条数）
- [ ] 信号表研判列含影响方向+建议动作
- [ ] 无重复段落

## 三、数据与口径

- [ ] 企业数/风险条数/舆情条数与取数结果一致
- [ ] 金额带单位（万元/亿元）
- [ ] 股东表数据来自取数（禁止"详见工商登记"占位）
- [ ] 企业名无尾部标点
- [ ] 统计表数字与正文引用一致

## 四、形式与合规

- [ ] 第二章每节为【行业动态】+【区内动态】两段式
- [ ] 行业表第二列="细分行业"（真实细分行业，非行业大类）
- [ ] 动态列无"（N条合并）""（来源：xxx）"标注
- [ ] 页眉日期为报告当期
- [ ] 无占位符、无内部字段名（company_id/接口名）
- [ ] 无空括号（）、无"纠纷纠纷"类重复
- [ ] 无动态企业不进入重点企业表

## 五、逻辑一致性

- [ ] 重点关注企业在深化分析和信号提示中的口径一致
- [ ] 跨期对比准确（"连续两月"等表述有依据）
- [ ] 报告组织维度与企业集合的实际区域/行业分布一致
