# 企业风险监控报告

对单家或多家企业生成风险监控报告。本技能负责业务逻辑与报告生成；数据通过取数工具获取（见 `references/hydc命令映射.md`），不直连外部 API，不接触密钥。

## 适用边界（正向界定）

**本技能只做一件事**：对单家或多家企业生成风险监控报告（交付型文档）。

- 触发信号：用户要求"生成/出/做一份企业风险监控报告、风险报告、监控月报"等交付型文档
- 除此之外的意图（查企业、问情况、产业问答、筛选罗列企业）均**不属于**本技能，走常规问答

## 交互原则：能默认就默认，不打断用户

| 参数 | 默认 | 说明 |
|---|---|---|
| 企业集合 | 前文/附件已有名单或筛选规则→直接用 | **仅当完全没有时**提示一次：请提供名单或筛选条件 |
| 监控周期 | 当月（月度口径） | 不打断；用户指定周期则用其指定；默认时提示"当前按月度口径，需要其他周期可更新" |
| 输出形式 | word（docx） | 不打断；用户指定 html 等则按其指定（调用其他生成制品的技能/工具） |
| 企业规模 | ≤200 家逐家分析；>200 家默认整体画像+聚合统计 | 见下"规模引导" |

**企业集合理解有歧义时**才复诵确认一次，否则直接执行。

## 企业集合的来源

本技能自"拿到企业集合"开始。集合来源开放：
- 用户提供的名单（附件/前文）
- 上游工具按筛选条件（区域/产业/被投资/融资过等）筛定的企业集

本技能**不负责企业筛选**；筛选由上游工具完成。

## 规模引导（>200 家时）

默认给"整体画像+聚合统计"，并提示用户：
> "当前范围较大（N 家）。已为您生成整体画像；可缩小范围（按行业/区域收敛），或点名重点关注的企业做深度分析。"

用户点名深度分析的企业，再做逐家取数与深化。

## 工作流程

```
1. 定集合    企业名单（用户提供）或上游工具筛定的企业集
2. 集合画像  统计集合的注册地分布、行业分布，反推报告的区域与行业组织维度
             （用户给了区域/行业入参则用入参；没给则从企业数据反推；
              跨区域集合按主导区域落地、其他区域单列）
3. 取数      按 references/hydc命令映射.md 逐步取数
4. 组装素材  企业→行业分组→事件/股东/舆情汇总
5. 识别重点  按企业风险条数/风险等级/舆情热度自动识别重点企业（用户点名时优先）
6. 分析生成  按 references/生成规则.md 的框架写报告（MD）
7. 转换      MD → docx（新华社公文格式，见 references/格式规范.md）
8. 自检      按 references/自检清单.md 通读核对，通过才交付
```

**报告维度跟着集合走**：行业分析按企业实际所属行业分节（不预设固定行业分类）；"对我区影响"按企业注册地主导区域落地。

## 取数

数据通过取数工具获取，步骤→命令→取数的映射见 `references/hydc命令映射.md`。该映射为当前口径；具体命令与字段以取数工具 `help` 查询的当前 schema 为准。按需取数、取够即停。

## 报告结构（默认）

概述（监测说明+总体监测情况）→ 行业分析（每行业：行业动态+区内动态+重点企业动态表）→ 重点企业深化（每家四段式）→ 信号提示（重点关注/积极/平稳）→ 新注册企业追踪 → 总体研判 → 附录1监测名录 / 附录2新注册名录。

写作规则、禁忌清单、分析框架见 `references/生成规则.md`。

## 断点续跑

大报告分片落盘，中断后从断点续：
- 取数层：企业分片取数，结果存 `processed/events_分片N.json`，进度记 `progress.json`
- 生成层：分章写 MD
- 重跑时跳过已完成分片与章节

## 错误处理

- 取数全部失败：报原因并中止
- 部分失败：照常生成，交付时注明缺失的具体企业名单与环节，询问是否重试补缺
- 命令不熟：先 `help` 查 schema，不臆造命令与字段

## 分析边界

- 事实与推断分开，标注数据口径与时间范围
- 缺数据就明说，不用推测填充
- 空结果/报错视为数据限制，不等于"无此企业/无此事"
