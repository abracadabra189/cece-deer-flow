基线样张：《上海市类脑智能 产业洞察报告》。标准骨架如下，`spec.json` 由其实例化。

## 0. 封面 / 执行摘要 / 封底

1. 封面：见 `html-rules.md §1`；增强项：报告编号 `<industry_code>-<region_code>-<as_of>` 与版本 v1 置于免责句上一行 9pt。
2. 执行摘要（1 页，新增）：评分结论一句话 + 3–5 条关键发现（每条=事实数字+含义）+ 数据范围一句话（as_of、来源、口径）。
3. 封底：见 `html-rules.md §4`。

## 2. 增强章（样张之外，强制）

- 六 方法论与数据口径：评分模型（六维、满分 100）、企业价值模型（六维 0-100）、专利价值模型（三维 0-10）说明；数据截至日、来源、口径与限制声明（缺失数据集逐条列明）。
- 七 结论与建议：仅由校验过数据支撑的条件式建议；事实与推断分句。
- 附录 A 指标定义；附录 B 全量数据表（Top10 之外完整表，若数据可得）；附录 C 图表索引（图号/图题/页码）。

## 3. 数据范围块（强制）

每图每表必带：`截至：YYYY-MM-DD　数据来源：<source>`（source 取自 `data_manifest.json`）。

## 4. 表格规范

跨页重复表头；数值右对齐千分位；单位入表头；表题上、表注下；长文本列限宽换行，单元格超 6 行截断并指向附录 B。

## 5. 分析推理规范（每节三段）

1. 观察（What）：只引用数据包数字的模板事实段（槽位插值，话术对齐样张）。
2. 归因（Why）：分析段，须标注依据或列为假设；禁止无源因果。
3. 含义（So What）：条件式含义/建议；风险与异动用红色强调，事实强调用蓝色。
事实句与推断句不得混在同一句；缺数据写"数据暂缺"，不推测填充。

## 6. 数字与文本规范

千分位英文逗号；百分比两位小数；金额统一展示单位（万元/亿元）并存元值；日期 `YYYY-MM-DD`；
章标题"一、二、…"、节"3.1"、子节"(1)"；禁用"章节/部分"前缀与夸张词（解码、DNA、秘诀等）。
