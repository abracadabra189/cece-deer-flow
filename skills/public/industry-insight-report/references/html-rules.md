# HTML 渲染标准规则（分页 / 封面 / 页眉页脚 / 图表 / 表格）

页面：A4 210×297mm；`.page` 固定尺寸容器，`page-break-after: always`；`@page { size: A4; margin: 0 }`。
正文页内容盒：宽 178mm（左右边距各 16mm），高 243mm（上 18mm 含页眉、下 16mm 含页脚之间）。
页眉/页脚/页码作为每页重复 DOM 渲染（不依赖 running elements），封面与封底不渲染页眉页脚页码。

## 2. 页眉（正文每页）

高 12mm，顶边距 10mm，左右对齐 16mm 边线：
- 左：logo 8mm 方块 + "行业洞察" 10.5pt 加粗 `#333E48` + 其下"产业数据服务平台" 6.5pt `#9AA5B1`（字距 0.6mm）；
- 右："产业洞察报告" 10.5pt `#8A94A6`，与 logo 垂直居中对齐；
- 页眉下不留分割线，与正文首块间距 6mm。

## 3. 页脚（正文每页）

页码居中，距底 8mm，9pt `#333333`；正文首页编 1；封面/封底无页码。

## 4. 封底（back cover）

- 波浪带置于右上（封面波浪的镜像简化版）；
- 居中：logo 20mm + "行业洞察" 22pt `#333E48` + "产业数据服务平台" 12pt `#9AA5B1` + 网址 14pt `#9C27B0` 下划线；
- 底部信息条：左侧二维码占位 22mm（`assets/qr_placeholder.svg`，有授权资产后替换），右侧"中国经济信息社上海总部" 12pt 加粗 + 细分割线 + 地址/邮箱 10pt `#333333` 双栏。

## 5. 分页装箱规则（build_html）

- block 类型：`h1/h2/h3/para/scope/chart/table/note`；高度估算：para = ceil(字数/47)×6.7mm；h1=14mm、h2=11mm、h3=9mm（含间距）；scope=6mm；chart = 图高+标题 10mm+scope 6mm；table = 表头 8mm + Σ行高（行高 = 7mm × ceil(最长单元格字数/该列字数上限)）。
- 贪心装箱：块不可跨页（table 除外）；`h2/h3` 必须与后继块同页（widow 控制）；table 按行切分跨页且每页重复 `<thead>`，切分不落在单元格内部（超长单元格先截断+附录全文）。
- 单图高度 ≤120mm、宽 ≤178mm；一页最多 2 图；图与表不混排同页（除非剩余空间足够整块）。

## 6. 图表与表格样式

- 图表为内联 SVG（`render_charts.py` 生成），无外部 JS/CSS/图片；`charts.json` 存档 spec 便于复渲染。
- 图题居中 11pt `#333` 置于图上；数据范围块（`截至：YYYY-MM-DD　数据来源：<source>`）9pt `#8A94A6` 居中置于图题下。
- 表题居中 11pt 置于表上；表头底色 `#EFF3F8`、10pt 加粗；正文 10pt；数值列右对齐、千分位英文逗号；单位入表头；表注（来源/口径）9pt `#8A94A6` 置于表下。
- 强调色：事实强调 `#1667B8`；风险/异动 `#E64545`；章标题 `#1667B8` 加粗；节标题同色小一号。
- 色板与字体 tokens 见 `assets/theme.json`；打印友好、色盲可辨；图例置底、标签防重叠（>8 类合并"其他"）。

## 7. 单文件自包含

`report.html` 必须内联全部 CSS/SVG；禁止外链 css/js/img/font；禁止 `NaN/undefined/None` 文本泄漏（check_html 硬门）。
