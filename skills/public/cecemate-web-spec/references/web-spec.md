# CeCeMate 网页产出物 UI/UX 标准规范

|   |   |   |   |
| --- | --- | --- | --- |
| **版本** v1.1　 | 　**生效** 2026-11-19　 | 　**适用范围** 单文件 HTML / 静态站点　 | 　**配套** `check/check_web.py` · 核心结构检查 |

本规范约束 CeCeMate 以 HTML 形式交付的一切产出物：行业洞察、财务分析、投研简报、项目复盘、运营周报、政策解读、方案说明、数据看板、教学材料等。规范的边界是**视觉与结构**，不约束内容主题；任何一个业务场景都应能在模块库中找到对应组合，而不是被迫套用某一份报告模板。文档（Word/PDF）侧的规则另见《CeCeMate 文档产出物 UI/UX 标准规范》。

> **本规范自身即合规样本。** 页头的行业洞察logo、正文最后一节的篇尾免责区、页脚版本信息，都是产出物必须具备的结构，不是本规范页的装饰。任何生成结果都不得删除其中任一项。

## 01 适用范围与边界

规范管三件事：**结构可以有哪些区块**、**每个区块长什么样**、**什么内容必须出现且不可删**。不管三件事：业务结论是否正确、数据是否完整、叙事是否有说服力——那属于内容生成规则，不在本规范内。

### 1.1 该用网页还是文档

| 判断依据 | 用网页（本规范） | 用文档（另见文档规范） |
| --- | --- | --- |
| 阅读方式 | 屏幕浏览、滚动、分享链接 | 打印、签署、归档、邮件附件 |
| 内容体量 | 单页可承载 6–10 个区块，图表交互 | 20 页以上长文、章节编号、目录 |
| 数据形态 | Echarts图表为主，表格为辅 | Echarts图表为主，表格为辅 |
| 交付要求 | 需要链接、需要随时更新 | 需要盖章、需要版本留痕、需要离线存档 |

同一份内容两边都要时，**不要直接把网页打印成 PDF**：网页的 sticky 页头、栅格断点、交互控件在纸面上全部失效。应按文档规范重新排版。

### 1.2 硬性项与可选项

- **硬性**：行业洞察logo、免责声明、数据说明、页脚——四者缺任一即为不合格产出。
- **可选**：指标卡、图表、提示块、时间线、矩阵、动作按钮——按场景取用，宁少勿多。
- **禁止**：新增规范外的组件类型、自造色值、装饰性渐变、emoji 作为图标、轮播与自动播放动画。

## 02 设计原则

五条原则按优先级排列。冲突时上位原则胜出，不存在“为了好看而牺牲下位”的例外。

| 原则 | 含义 | 落地判据 |
| --- | --- | --- |
| **数据先于装饰** | 页面上每个视觉元素都要承载信息 | 删掉该元素后信息不减少，则该元素应删 |
| **一色一义** | 颜色是语义，不是调色 | 蓝色只表示强调与主操作，状态色只表示状态，灰色只承担层级 |
| **描边分层** | 用 1px 线划分层级，不用阴影 | 全站 `box-shadow` 为零；层级差 = 底色差 + 描边差 |
| **可核对** | 任何结论都能追到来源 | 每个图表有口径，每个数字有单位，每处推断有标识 |
| **克制** | 版式服务阅读，不争夺注意力 | 无渐变、无动效、无 emoji、标题无彩色竖条 |

> **最常见的三类不合格。** 标题左侧加彩色竖条（把装饰误当层级）、标签用实底彩块（把标签做成按钮）、卡片加投影（把网页做成 PPT）。这三种在本规范里都是明确禁止项，须在人工视觉复核中判定。

## 03 品牌与行业洞察logo（强制）

品牌标识是产出物归属的唯一凭证。**任何场景、任何页数、任何导出格式，行业洞察logo 都不得删除、不得替换、不得弱化。** 这一条优先级高于本规范其他所有条目——版面再紧，也只能压缩内容，不能压缩行业洞察logo。

![行业洞察logo](../assets/logo.png)

### 3.1 资产

| 项 | 值 | 说明 |
| --- | --- | --- |
| 文件 | `assets/logo.png` | 行业洞察logo 的唯一合法来源；文件名保持不变，不得重绘、不得用文字拼近似标识 |
| 尺寸 | 2529 × 480 px | 宽高比 `5.27 : 1`，横向锁定 |
| 底色 | 透明（RGBA） | 不得垫白底块、不得加描边、不得加阴影 |
| 格式 | PNG | 不得转 JPG（会丢失透明通道并产生杂边） |

### 3.2 出现位置与尺寸

| 位置 | 高度 | 次数 | 约束 |
| --- | --- | --- | --- |
| 页头 | 34px | 1 | 顶栏 `position:sticky`，白底 + 底部 1px 描边；行业洞察logo 垂直居中，左侧对齐版心 |
| 页脚 | 22px | 1 | 与来源说明、版本信息同区；页头页脚高度比约 `1.55 : 1` |
| 分享卡片 / og:image | ≥ 40px | 1 | 社交分享缩略图左上角必须带行业洞察logo |

两处行业洞察logo 必须来自同一个文件。禁止页脚用灰度版、降低不透明度或缩小到不可辨识（\< 16px 高）。

页面骨架与行业洞察logo 双位置示意（自上而下三段，不可调换顺序）：

- **页头** · 高 64px · `position:sticky; top:0; z-index:100` · 白底 · 底部 1px gray-400
  - 左：行业洞察logo 34px，垂直居中，左边缘对齐版心
  - 右：报告编号与更新时间，12px gray-900
- **内容区** · 版心 1200px · 左右 28px · 区块间距 20px
  - 标题区（M1）：主标题 32px / 导语 14px / 元信息芯片 3–5 个
  - 指标卡 ×4（M2）：`repeat(4,1fr)`，卡间距 16px
  - 主图表（M3，1.55fr）+ 辅图表（M3，1fr）：两栏等高
  - 正文区块 / 数据表（M4 / M5）
  - **篇尾免责区（M9）**：内容区最后一节，通栏 gray-100 底 + 上边线 1px gray-400
    - 短句 13px/600 + 长版 12px；不加圆角、不投影，与页脚之间不留其他区块
- **页脚** · 白底 · 顶部 1px gray-400
  - 行业洞察logo 22px（与页头同一文件）+ 来源说明 + 版本信息，12px gray-900

页头行业洞察logo 高 34px，页脚行业洞察logo 高 22px，同一文件、同一透明度。

### 3.3 禁令

- 不得删除、注释掉、`display:none`、`visibility:hidden`、`opacity` 低于 1、移出视口或藏进折叠区。
- 不得改色、加滤镜（`filter`）、加背景色块、加描边、加圆角遮罩、加投影。
- 不得裁切、拉伸、非等比缩放；宽度必须由高度推导（`height` 定值 + `width:auto`）。
- 不得与标题、标签、按钮贴边：四周留白 ≥ 行业洞察logo 高度的 0.5 倍。
- 不得因“内容太满”而省略——内容溢出应通过删减模块解决，不是删行业洞察logo。

> **换品牌时只换文件。** 替换 `assets/logo.png` 即可，尺寸规则、出现次数、留白要求一律不变。不要为了适配新标识的宽高比而改版式——若新标识比例差异过大，应等比缩放后按高度对齐，而不是拉伸。

## 04 设计令牌

所有色值、字号、间距必须通过 CSS 变量引用。生成物中除 `:root` 定义处外，不得出现裸色值（`#HEX`、`rgb()`、`hsl()`）；本节列出的令牌即为当前规范的唯一来源。

| --- | --- | --- |
| `--blue-100` | `#E8F3FF` | 主色浅底 |
| `--blue-200` | `#C9E3FF` | 浅底描边 |
| `--blue-300` | `#94C7FF` | 焦点外环 |
| `--blue-400` | `#459DFF` | 图表辅助 |
| `--blue-500` | `#1B84F9` | hover 提亮 |

| `--blue-700` | `#004FC1` | 按下态；深色文字 |
| `--blue-800` | `#0043A0` | 深调；分级设色最深档 |
| `--blue-900` | `#032D7B` | 仅地图末档 / 打印 |

### 4.3 状态色与图表色板

| 令牌 | 色值 | 语义 |
| --- | --- | --- |
| `--green-600` | `#00B877` | 达标 / 增长 |
| `--red-600` | `#E62C3B` | 风险 / 下滑 |
| `--orange-600` | `#FF7400` | 关注 / 预警 |
| `--gold-600` | `#FFAC00` | 待办 |
| `--chart-1` | `#5B8FF9` | 分类序列 1 |
| `--chart-2` | `#30D699` | 分类序列 2 |
| `--chart-3` | `#F6BD16` | 分类序列 3 |
| `--chart-4` | `#F6903D` | 分类序列 4 |
| `--chart-5` | `#E892A6` | 分类序列 5 |
| `--chart-6` | `#7A77C9` | 分类序列 6 |
| `--chart-7` | `#5EC1B0` | 分类序列 7 |
| `--chart-8` | `#3BA55C` | 分类序列 8 |

图表分类色板共 8 色，顺序固定：`#5B8FF9 → #30D699 → #F6BD16 → #F6903D → #E892A6 → #7A77C9 → #5EC1B0 → #3BA55C`。同一份产出物内，同一维度必须始终使用同一颜色；不得为了“配色好看”打乱顺序。

### 4.4 语义锁色

| 色 | 允许用于 | 禁止用于 |
| --- | --- | --- |
| blue-600 | 主操作、强调数值、信息类标签、图表主序列 | 风险、下跌、警示 |
| green-600 | 达标、增长、正向变化 | 品牌、装饰 |
| red-600 | 风险、亏损、下滑、负向变化 | 强调标题、错误页以外的装饰 |
| orange / gold | 关注、预警、待办 | 与红绿混用表达同一语义 |

**蓝色配额：蓝 : 白灰 ≈ 1 : 9（面积比）。** 蓝色是强调色，不是底色。一整屏看过去，蓝只该出现在六处：主标题的关键短语、当前选中项、图表主序列、主操作按钮、表格数据条、地图分级设色。超过这个量，强调就失效了——一眼全是蓝，等于没有重点。

| 用途 | 取色 | 约束 |
| --- | --- | --- |
| 选中 / 当前态（实底） | blue-600 底 + 白字 | 指标卡组、页签；同组最多 1 个，其余回到 gray-100 底 |
| 选中态（浅底） | blue-100 底 + blue-700 字 | 表格选中行、图表 hover、目录当前项 |
| 数据条 / 进度条 | blue-600，底槽 gray-200 | 表格内比较；高 4px、圆角 2px、不写百分比标签 |
| 图表主序列 | blue-600，面积 6% 透明 | 辅序列按 chart-2…8 顺序，不另造蓝色深浅代替分类 |
| 地图分级设色 | blue-100 → blue-800 五档 | 单色阶，不用彩虹色；必须用带审图号的合规底图 |
| 链接 / 主按钮 | 常态 blue-600、hover blue-500、按下 blue-700 | 全页主按钮 ≤ 2 个 |

**参考界面怎么取。** 行业数据看板（产品后台）那一版配色可直接沿用三件事：白卡片 + 1px 灰描边 + 浅灰页底、选中卡整卡实底蓝、表格里用蓝色细横条做量级比较。另有两处**明确不采纳**——

- **卡片左上角的彩色小竖条**（橙 / 绿 / 蓝多色编码）：颜色一多就不再是语义而是装饰，且色盲用户无法区分。分类改用中空文字标签。
- **浅蓝实底标签**：实底会被读成按钮。标签一律中空描边，浅蓝底只留给“选中态”。

### 4.5 字号阶梯

| 令牌 | 字号 | 字重 | 行高 | 用途 |
| --- | ---: | ---: | ---: | --- |
| `--fs-display` | 32px | 600 | 1.25 | 页面主标题，全页仅一处 |
| `--fs-title` | 20px | 600 | 1.4 | 章节标题 |
| `--fs-subtitle` | 16px | 600 | 1.5 | 小节标题 |
| `--fs-card-title` | 14px | 600 | 1.5 | 卡片标题 |
| `--fs-body` | 14px | 400 | 1.75 | 正文 |
| `--fs-small` | 13px | 400 | 1.75 | 表格正文、卡片描述 |
| `--fs-caption` | 12px | 400 | 1.5 | 辅助说明、标签、图表轴标签 |
| `--fs-micro` | 11px | 400 | 1.5 | 来源、脚注；**全站最小字号，不得再小** |
| `--fs-metric` | 26px | 600 | 1.2 | 指标数值 |

中文正文行长控制在 38 汉字以内（`max-width:38em`），导语可放宽至 64em。行长超过 44 汉字时阅读效率显著下降，必须分栏或分段。

### 4.6 间距、圆角、描边

- 间距以 4px 为基数：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 36 / 48。
- 区块间距 `20px`，卡片间距 `16px`，页面左右留白 `28px`，最大版心 `1200px`。
- 圆角：`2`（标签、芯片）/ `4` / `6`（卡片）/ `8`（容器）；不得使用 50% 或 ≥12px 的大圆角。
- 描边统一 `1px`：卡片与区块用 gray-400，内部分割用 gray-300/400；不得使用 2px 以上描边，不得使用虚线表达层级。
- 全站零阴影。层级靠“页底 gray-200 → 分区白底 → 卡片 1px 描边 → 指标卡 gray-100”四层叠出。

## 05 页面骨架

骨架固定为三段：**页头（含行业洞察logo）→ 内容区（末节为篇尾免责区）→ 页脚（含行业洞察logo）**。内容区内部按模块库自由组合，方向是自上而下单向阅读，页头不再承载声明。

| 区域 | 高度 | 规则 |
| --- | --- | --- |
| 页头 | 64px | `sticky; top:0; z-index:100`；白底；底部 1px gray-400；左行业洞察logo（34px），右报告编号与更新时间（12px gray-900） |
| 内容区 | 自适应 | 版心 1200px；左右 28px；区块间距 20px；**最后一节固定为篇尾免责区** |
| 篇尾免责区 | 自适应 | gray-100 底；上边线 1px gray-400；短句 13px/600 + 长版 12px；**必须在内容区最末、紧接页脚** |
| 页脚 | 自适应 | 白底；顶部 1px gray-400；行业洞察logo（22px）+ 来源说明 + 版本信息 |

### 5.1 栅格

- 12 列，列间距 `16px`，不设固定列宽，按 `fr` 分配。
- 指标卡：4 张等宽（`repeat(4,1fr)`）；3 张时 `repeat(3,1fr)`；2 张时 `repeat(2,1fr)`。禁止 5 张以上，超出改表格。
- 双栏区：主栏 `1.55fr` + 辅栏 `1fr`，如“折线图 + 环形图”“正文 + 关键发现”。
- 不等高的双栏卡片，用 `align-items:stretch` 拉齐，禁止出现一高一低。

## 06 模块库与场景映射

模块共 9 个，编号 M1–M9。**可减不可增**：可以按场景跳过某个模块，但不能发明规范外的模块。M8、M9 为强制项，任何场景不得省略。

| 编号 | 模块 | 内容 | 约束 |
| --- | --- | --- | --- |
| M1 | 标题区 | 主标题 32px / 导语 14px / 元信息芯片行 / 状态标签行 | 芯片 3–5 个，等长优先 |
| M2 | 指标卡组 | 2–4 张独立卡，每卡“标签 + 数值 + 单位 + 变化” | 不得用分割线拼成一整块 |
| M3 | 图表区 | 折线 / 柱 / 环形 / 横向条，单图或主辅双图 | 每图必有标题与口径 |
| M4 | 数据表 | 表头 + 数据行 + 合计行 | ≤ 8 列，超出拆表 |
| M5 | 结论区 | 左正文（38em）+ 右“关键发现”面板 | 面板条目 3–5 条，带序号 |
| M6 | 清单矩阵 | 2×2 或 3×2 描边卡，或风险矩阵 | 每卡一枚状态标签 |
| M7 | 时间线 | 纵向节点 + 日期 + 事件 | 节点 4–7 个，按时间倒序 |
| M8 | 数据说明 | 来源、口径、时间范围、已知局限 | **强制**，12px gray-900 |
| M9 | 篇尾免责区 | 短句（加粗）+ 长版全文，贯穿内容区全宽 | **强制**，逐字锁定，必须是内容区最后一节 |

### 6.1 九类场景的模块序列

| 场景 | 模块序列 | 侧重 |
| --- | --- | --- |
| 产业 / 企业洞察 | M1 · M2 · M3 · M4 · M5 · M6 · M8 · M9 | 图表 + 研判 |
| 财务分析 | M1 · M2 · M4 · M3 · M5 · M8 · M9 | 表格优先 |
| 尽职调查 | M1 · M5 · M4 · M6 · M8 · M9 | 以表为主，可无图 |
| 竞品对比 | M1 · M4 · M3 · M5 · M8 · M9 | 对比矩阵 |

## 07 组件规范

### 7.1 指标卡

卡内固定三段，顺序不可调换：

- **标签**：12px gray-1000；右上角挂 18px 描边图标（gray-700，`stroke-width:1.6`，无填充）
- **数值 + 单位**：数值 26px/600 / 行高 1.2 / gray-1200 / `tabular-nums`；单位 12px gray-900，紧随数值右侧、**不加空格**
- **变化行**：12px；`↑ 23.8%` green-600、`↓ 0.9pct` red-600、`— 持平` gray-1000，后接“同比”二字

**示例：M2 指标卡组（四张等宽）**

| 标签 | 数值 | 单位 | 变化行 | 变化色 |
| --- | ---: | --- | --- | --- |
| 成交总额 | 18,426 | 万元 | ↑ 23.8% 同比 | green-600 |
| 退款率 | 3.6 | % | ↓ 0.9pct 同比 | red-600 |
| 客单价 | 286 | 元 | ↑ 4.1% 同比 | green-600 |
| 复购用户占比 | 31.2 | % | — 持平 同比 | gray-1000 |

卡片外观：gray-100 底 + 1px gray-400 描边 + 6px 圆角，内边距 14px 16px 13px。

- 指标卡是唯一允许使用 gray-100 浅底的卡片；其余卡片一律白底 + 1px 描边。
- 数值不做单位换算猜测：数据给万元就写万元，不擅自折算成亿元。
- 变化行没有同比数据时写“— 无同比”，不留空、不写 0。
- 2–4 张。只有 1 个指标时改用“带状强调块”，不做单张卡。

### 7.2 标签（中空）

示例：`● 达标`（green-600）　`● 风险`（red-600）　`● 关注`（orange-600）　`● 信息`（blue-600）　`● 待办`（gold-600）　`中性`（gray-1000）

标签一律中空——透明底 + 1px `currentColor` 描边 + 2px 圆角 + 文字与描边同色；状态类标签前置 5px 同色圆点。

禁止实底彩签、禁止“浅底深字”胶囊、禁止标签内放图标或关闭按钮。标签不是按钮，不加 hover 态。

### 7.3 数据表

| --- | ---: | ---: | ---: | ---: | ---: |
| 直播 | 6,842.3 | 37.1% | +41.2% | 312 | 4.1% |
| 货架 | 5,186.9 | 28.2% | +12.6% | 274 | 3.2% |
| 内容种草 | 4,092.5 | 22.2% | +18.4% | 248 | 5.8% |
| 私域 | 2,304.9 | 12.5% | −6.3% | 336 | 2.7% |

示例：M4 数据表。列数 ≤ 8；数值列右对齐 + `tabular-nums`；缺失值写“暂无公开数据”，不留空、不写“—”了事。

- 表头 gray-100 底 + 1px gray-300 线；表体只用横向分割线，不画竖线（键值表除外）。
- 有合计行时，合计行加 1px gray-600 上边线并加粗首列，不加底色。
- 单位写在表头括号内，不在每个单元格重复；不得把单位塞进单元格文字。

### 7.4 提示块

> **信息。** 用于口径说明、背景补充、名词解释。同一页面不超过 3 处。

> **正向。** 用于达标结论、达成共识的判断。

> **关注。** 用于需要人工复核的数据、口径不一致之处。

> **风险。** 用于明确不利结论、合规风险、口径缺陷。

提示块四态。白底 + 1px gray-400 描边 + 圆角 6px；**左侧不加彩色竖条**，仅图标着色。

### 7.5 结论区与关键发现面板

示例：M5 结论区。左右分栏，`grid-template-columns:1.55fr 1fr` + `align-items:stretch`，两栏等高。

- **主栏 · 综合研判**
  - 小标题 14px/600 gray-1200，下留 8px
  - 正文 14px / 行高 1.9 / 行长 38 汉字；关键判断用 blue-600 强调，**不整段加粗**
  - 段落之间空一行，不缩进，不用小标题切碎长段
- **辅栏 · 关键发现**（白底 + 1px gray-400 描边）
  - 面板标题条 14px/600，底部 1px gray-300 分隔
  - 条目 3–5 条，序号 `01 / 02 / 03` 用 gray-900 `tabular-nums`，与文字间距 10px，条目间距 10px
  - 标题右侧可挂中空计数标签

条目示例：`01 直播渠道贡献主要增量`　`02 内容种草退货率偏高`　`03 私域连续两期下滑`

### 7.6 风险矩阵 / 清单卡

2×2 或 3×2 描边白卡，卡内顺序固定：状态标签 → 名称（13px/600）→ 描述（13px/1.75 gray-1000）。**禁止左侧彩色竖条**。矩阵形式（影响 × 概率）用 2×2 网格 + 单元格内浅灰底区分，不填饱和色块。

### 7.7 时间线

示例：M7 时间线，按时间倒序。

- 2026-11-11　大促正式开售，首小时成交 3,120 万元
- 2026-11-10　预售尾款支付开启，退款咨询量峰值
- 2026-10-20　预售启动，定金转化率 42.6%

结构规则：竖线 1px gray-400；节点 7px 实心圆 + 3px 白描边环（用 `box-shadow` 画环**仅限此处**，不视为投影）；末条竖线设为透明；日期 12px `tabular-nums` gray-900，事件 13px gray-1000；节点 4–7 个。

### 7.8 动作元素

产出物默认是只读材料，若确需操作（下载、切换口径），最多两种：

- **主操作**：blue-600 实底、白字、6px 圆角、高 32px、左右 14px。
- **次操作**：白底、1px gray-400 描边、gray-1100 字。
- 两种都需 `:focus-visible` 2px blue-300 外环；`:hover` 仅变色不改尺寸。
- 禁止第三个按钮、禁止图标按钮（无文字标签）、禁止浮动操作按钮。

## 08 图表规范

图表是网页产出物的主体信息载体。选型先定关系，再定形式，最后才配色。

| **要表达的关系** | **图表类型** | **说明** |
| --- | --- | --- |
| 时间趋势 | 折线图 | ≤ 3 条线；超过 3 条改用小多图或“重点线 + 灰底线” |
| 类别对比 | 柱状图 / 横向条 | 类别名长于 6 字用横向条；排序后展示 |
| 构成占比 | 环形图 | ≤ 6 段；必须给出总计值；段间白描边 1.5px |
| 分布 | 散点 / 直方 | 须标注样本量 |
| 转化路径 | 漏斗 | 每层标绝对量与转化率 |
| 产业层级与连接（交互分布） | 桑基图 / 产业分布图谱 | 节点自左向右逐级展开，节点色按“企业数（家） 0 — 10,000+”色阶；保留节点总数、数据更新时间与图例；禁止多色区分层级。 |
| 产业链与创新点对应（静态） | 双带结构图谱 | 浅蓝“产业链”带在上、浅橙对应条目带在下，节点为白底圆角矩形，细连接线一一对应；图题与节点名逐字取自源材料。 |
| 地理分布 | 地图 | 仅用合规底图（腾讯位置服务 / 高德 / 百度 / 天地图），坐标 GCJ-02；国界、台湾、南海诸岛按国家标准绘制；前端不得写入地图 API Key。 |

> **三段式禁用。** 禁止 3D 图、禁止双 Y 轴（除非明确标注且两轴量纲无关）、禁止饼图超过 6 段。这三类在规范里一律判不合格。

### 8.1 ECharts 配置基线

| **项** | **取值** |
| --- | --- |
| 版本 | 固定 echarts@5.4.3，CDN fastly.jsdelivr.net；不得用 latest |
| 轴线 | gray-500，axisLine.show 与 axisTick.show 均 false |
| 分割线 | gray-300，仅 Y 轴 |
| 轴标签 | 12px gray-1000；刻度 11px gray-900 |
| 网格 | grid.containLabel:true；四周留白 8–16px，防止标签被裁 |
| 折线 | width 2、symbol:circle 7px 白描边 2px、smooth:0.25、面积 rgba(1,106,222,0.06) |
| 数值标注 | 11px；点数 &gt; 8 时只标首末与极值，避免标签互相重叠 |
| 环形 | radius:\["46%","70%"\]、padAngle:1、白描边 1.5、默认隐藏标签，hover 显示“名称 + 百分比” |
| 图例 | 置底，roundRect 8×8，间距 16，12px gray-1000 |
| 空数据 | 不画空坐标系，改为占位文案“暂无可比数据”，高度锁定避免塌陷 |
| 产业分布图谱 | series.type:"sankey"；节点竖条 nodeWidth:8、nodeGap:8，label 置于节点右侧，lineStyle.color:"gradient"、opacity:0.25，emphasis.focus:"adjacency"；色阶取“企业数（家） 0 — 10,000+”，不随主题改写。 |
| 双带结构图谱 | 静态输出，不走 ECharts 交互图表；若必须置于同一容器，用 graphic 元素绘制节点与连接线并设 animation:false，颜色取蓝带 / 橙带令牌，节点文字逐字取自数据。 |
| 地图 | series.type:"map" 或 geo；底图数据仅用合规来源导出的行政区边界，坐标 GCJ-02；roam 默认关闭，emphasis.label.show:false 避免地名压盖；国界、台湾、南海诸岛按国家标准绘制；禁止 Google / OSM 境外瓦片与前端明文 Key。 |

### 8.2 图表可核对性

- 每张图必须有标题（14px/600）与副标题（12px gray-900，写口径与时间范围）。
- 分段求和必须等于总量：两者都写成 JS 常量，避免手写两遍数字；交付前人工核对其一致性。
- 图表卡内不放大段文字解释；解释放正文，图表只承担数据。
- 打印时图表须转静态：`@media print` 下关闭动画与交互提示。

### 8.3 图表尺寸自适应（强制）

**所有图表必须随容器大小自适应**，尺寸由容器决定、不由脚本写死。图表卡内出现大片留白、图体缩在角落、类目名被压成单字或竖排，一律判不合格。

- 容器：绘图区 \`width:100%\`，高度按类型给基准下限——折线 / 柱 / 横向条 ≥ 280px，环形 / 饼 ≥ 240px，桑基 / 产业图谱 / 地图 ≥ 360px；尺寸只在 CSS 中定义，禁止在 JS 里用固定像素宽高覆盖。
- 初始化即适配：\`echarts.init(dom)\` 之后立即调用一次 \`chart.resize()\`，确保首帧按容器实际尺寸绘制，禁止只渲染一次就结束。
- 持续适配：用 \`ResizeObserver\` 监听绘图区容器，并在 \`window.resize\` 回调中再次调用 \`chart.resize()\`；禁止用定时器轮询代替。
- 状态变化后重算：容器由隐藏变显示、Tab 切换、折叠展开、异步数据回填后，都要再次 \`chart.resize()\`，防止尺寸塌陷成细条或图体滞留旧尺寸。
- 横向条：保持 \`grid.containLabel:true\`，\`grid.left\` 按最长类目名动态留白（建议 ≥ 96px，或按字数 × 12px + 16px 估算），确保类目名完整横排显示；禁止把名称截断、压成单字或竖排，柱条按容器剩余宽度铺开。
- 环形图：\`radius\` 取容器短边百分比（沿用 46% 至 70% 的环宽设定），图例、中心总计值与图体放在同一容器内布局；禁止图体缩到角落而总计值远置造成大片空白，分段 ≤ 6，图例不堆叠成细长条。
- 占满与分配：单图占满所属卡片内容区；主辅双图按 \`1.55fr / 1fr\` 分配后各自 \`resize()\`，两图等高，禁止出现一侧图很小、旁边留白。
- 校验：生成后比对 \`chart.getWidth()\` / \`getHeight()\` 与容器 \`clientWidth\` / \`clientHeight\`，误差 ≤ 2px；在 1024px 与 720px 断点各核对一次截图，窄屏单列时图表仍须占满容器宽度。
- 打印与导出：先按打印宽度 \`resize()\`，再在 \`@media print\` 下关闭动画与交互提示，保证导出图与屏幕保持同尺寸关系。

## 09 免责声明（强制）

免责声明是资质性内容，不是装饰文案。位置只有一处：**篇尾**——内容区最后一节（M9），其下紧接页脚。**文案逐字锁定**，任何生成物不得改写、缩写、翻译或补句。

### 9.1 篇尾免责区的结构

自上而下三段，间距固定：

- **短句**：`内容由 AI 生成，请核实重要信息` —— 13px / 600 / gray-1100 / 行高 1.5；前置 15px 描边 ⓘ 图标（`stroke-width:1.6`，gray-900）
- **长版**：紧随短句，间距 8px；12px / 400 / 行高 1.75 / gray-900；首句必须是短句原文，之后补口径与免责范围
- **容器**：贯穿内容区全宽（与版心同宽、不缩进、不嵌进卡片、不受分栏约束），gray-100 底，上边线 1px gray-400，上下内边距 20 / 24px；**不加圆角、不加四边框、不投影**

长版标准文本（逐字使用，只替换方括号里的对象）：

> 内容由 AI 生成，请核实重要信息。本\[页/报告\]由 CeCeMate 智能体生成，可能存在遗漏、滞后或理解偏差；本\[页/报告\]不构成决策依据，据此操作风险自担。

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 文案 | 内容由 AI 生成，请核实重要信息 | 中文逗号，句末不加句号；不得写作“AI 内容仅供参考”等变体 |
| 位置 | **1 处，篇尾** | 必须是 `<main>` 的最后一个 `<section>`；与页脚之间不得插入任何区块（含“相关推荐”“更多阅读”） |
| 字号 | 短句 13px / 长版 12px | 不得小于 12px，不得降低不透明度，不得用 gray-700 以下对比度 |
| 色彩 | 中性灰 | gray-1100 短句 + gray-900 长版，gray-100 底；**不用红色警示**——它是事实陈述，不是故障提示 |
| 可访问 | 常显 | 不得放进折叠面板、tooltip、弹窗；不得提供“不再提示”关闭按钮；不得只留页脚小字 |

### 9.2 为什么只在篇尾

页头信息条会在首屏抢占视觉权重，却只出现一次；页脚小字则常年被忽略。篇尾是阅读的收束点——读者看完结论正要判断“能不能用”，此时告诉他“这是 AI 生成的、关键数据请核实”，说服力最强。

代价是长页面中途看不到。这个代价是刻意接受的：网页可整页滚动，读者总能到达篇尾；而把声明拆成三处只会让它变成背景噪音。**如果合规要求中途也必须可见，只能加页脚一行 11px gray-900 短句作兜底——但它不能替代篇尾区块。**（文档侧因纸不可滚动，保留了每页页脚，见文档规范第 13 节。）

导出为图片长图、PDF、分享卡片时，免责声明必须随图出现；分享卡片的副标题也要带“AI 生成”字样。

## 10 文案与数据表达

### 10.1 数字

| 类型 | 写法 | 规则 |
| --- | --- | --- |
| 数量级 | 1,284.6 亿元 | 千分位；万/亿单位保留一位小数；数与单位间一个空格 |
| 百分比 | +12.4%　−1.9pct | 正向带 +，负向用 U+2212；百分点变化用 pct 不用 % |
| 区间 | 3.2–4.8% | 用 en dash，前后不加空格 |
| 日期 | 2026-11-11 | ISO 格式；正文中可写“2026年11月11日”，同一文档内统一 |
| 缺失 | 暂无公开数据 | 不写“—”、不写 0、不写“未披露”以外的主观推测 |

### 10.2 措辞

- 客观陈述、数据先行，不用第一人称，不用感叹号，不用“我们认为”以外的模糊表述。
- 推断必须可识别：凡非原始数据的结论，写“据…推算”“以…口径估算”，不得与事实句混排。
- 不使用“颠覆”“爆发”“碾压”“遥遥领先”等营销词；程度用数据表达。
- 标题不超过 24 汉字，导语 60–120 字，卡片描述 30 字以内。

### 10.3 图标

仅用内联描边 SVG，`stroke-width:1.6`，无填充，`currentColor` 着色；指标卡 18px gray-700，区块标题前 15–16px gray-900。禁止 emoji、禁止图标字体、禁止多色图标、禁止图标替代文字标签。

## 11 交互与状态

产出物以阅读为主，交互只服务于“核对”，不服务于“表演”。

| 状态 | 规则 |
| --- | --- |
| hover | 仅图表高亮与链接变色；卡片不做上浮、不加阴影、不改边距 |
| focus | 键盘可达元素必须有 2px blue-300 外环 + 2px 偏移；不得 `outline:none` 后不补替代 |
| loading | 图表加载给出高度锁定的占位块，禁止整页转圈 |
| empty | 写明“暂无数据”及原因（未公开 / 不适用 / 未获取），不留白块 |
| error | 图表脚本失败时显示“图表需联网加载”的文字占位，**不得留空白区域**，不得整页白屏 |

禁止：自动轮播、滚动显现动画、视差、鼠标跟随、声音。任何动效时长不得超过 200ms，且必须可用 `prefers-reduced-motion` 关闭。
